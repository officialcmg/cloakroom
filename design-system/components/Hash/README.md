# Hash

A transaction hash, address or block reference, shortened to head and tail in `hash` type, with the full value on hover and an optional explorer link.

- Provide: `value` (the full string), optional `label` ("Escrow", "Claim"), `href` (an explorer URL), `head` and `tail` lengths (default 6 and 4).
- Shielded Zcash transactions link nowhere by default: an explorer shows nothing useful about them.
