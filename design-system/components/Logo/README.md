# Logo

The mark is a yellow claim ticket, a `zec` pill outlined in `line` with one punched hole in `ink`: the stub you hold while your coat (your ZEC) is checked. The wordmark is "cloakroom" in lowercase Archivo 800.

- Provide: `size` (the mark's height in px; the word scales with it), optional `markOnly` for favicons and tight spaces.
- Keep the mark's yellow; on a yellow ground use the mark only, never yellow on yellow.
- Do not pair it with the Zcash mark. The files are in the Logos group.
