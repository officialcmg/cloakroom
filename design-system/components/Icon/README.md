# Icon

Nine outline icons on a 24px grid with a 2px stroke, matching `stroke`: shield (shielded), lock (locked), clock (waiting), check (final), return (refunding), alert (action needed), copy, external and arrow.

- Provide: `name`, optional `size` (default 20) and `title`. Without a `title` the icon is decorative and hidden from screen readers.
- Icons take the text colour (`currentColor`), so colour them through their parent.
- An icon never stands alone for a state: it sits beside the word.
